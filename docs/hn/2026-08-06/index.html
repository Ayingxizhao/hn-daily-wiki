    Today's theme: AI agents and inference economics led the front page, alongside GitHub's latest outage and debates over device control, surveillance, and software craft.

    • Qwen3.8 Max now ranked as the best overall model by agentic index — The new best overall agentic model ranking is important for anyone choosing models for agent workflows, even if the index methodology is being questioned.
    • Humans missed 1 in 3 threats approving AI agent commands across 40k game runs — Real data from 40k game runs shows humans approving a third of suspicious agent commands; essential context for AI agent guardrails.
    • Inside vLLM: Anatomy of a High-Throughput LLM Inference System (2025) — A rare, detailed look at vLLM's internals beyond paged attention; useful for anyone working on LLM inference and serving.

    • DeepSeek planning to significantly raise prices — DeepSeek's significant API price increase changes the economics of using their models, so developers should plan accordingly.
    • LLMs won't break symmetric crypto — A grounded counterpoint to AI hype, explaining why LLMs won't crack symmetric crypto—a good mental model to keep.
